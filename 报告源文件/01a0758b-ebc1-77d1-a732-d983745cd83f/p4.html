（二）边缘端：从浮点权重到 BPU 定点模型

训练完成的 PyTorch 权重只有 10.2 MB，却是 int8 板卡读不懂的浮点格式。本环节的任务，是把它变成 RDK X5 能够直接执行的定点模型，并保证精度不发生明显损失。整条链路分为六步，每一步都对应一次真实的工程决策：

关键参数速查

项目取值与说明
量化工具链openexplorer/ai_toolchain_ubuntu_20_x5_cpu:v1.2.8-py310（hb_mapper 1.24.3 / hbdk 3.49.15 / horizon_nn 1.1.0）
目标架构march = bayes-e，即 RDK X5 的 BPU 架构
ONNX opset11——工具链仅支持该版本；导出时按目标版本做算子适配
模型接口输入 x1 / x2 各 [1,3,256,256]，输出 change_map
校准数据从训练集抽取 60 组真实 A/B 影像，按与训练完全一致的预处理生成 float32 裸数据（每组 786,432 字节）
量化配置calibration_type: default；cal_data_type: "float32; float32"；preprocess_on: False
产物repbnet_cd.bin，3,279,032 字节 ≈ 3.2 MB，较浮点权重压缩约 68%
预处理一致性（全链路最容易翻车的一点）：图像读取 → 6 通道拼接 → 归一化 → 减均值除标准差 → BGR 转 RGB → HWC 转 CHW，导出、校准、量化、板端推理四处必须完全一致。本作品将顺序固定为「x1 = 后时相 B 的 RGB、x2 = 前时相 A 的 RGB」，只要有一处不一致，输出就会整体崩坏。
多输入模型的配置规则：凡是与输入个数相关的参数，都要用分号分隔写同样多份（如 "float32; float32"），并分别指定各自的校准数据目录。这一条是配置阶段最常踩的坑。

功能构成

功能实现方式与作用
双时相切换对比前后时相影像叠放，拖动滑块即可对照同一位置的变化，便于人工复核
六视图联动前时相、后时相、人工标注真值、预测掩膜、叠加图、概率热力图同屏呈现
误差四色图以 TP（正确变化）/ FP（误报）/ FN（漏检）/ TN（正确负例）四类着色，暗调低饱和配色，一眼看出错在哪里、错成什么样
精度指标逐像素统计 Precision / Recall / F1 / IoU，并给出 TP、FP、FN、TN 计数，支持置信度阈值实时调节
变化区域点选自动串出连通区域列表，点击即可在原图上高亮定位，把「面积统计」变成可交互操作
AI 语义解释调用通义千问视觉大模型 qwen-vl-max，把双时相影像、叠加图与检测统计一并送入，输出「哪里变了、变成了什么」的中文短结论
设备实时监控读取板卡温度、内存与 CPU 占用，以火花线形式常驻显示，体现边缘设备的运行状态
批量评估对测试集逐对推理并与真值比对，累计 TP / FP / FN / TN，一次性给出全量指标
结果导出把当前结果图、指标与 AI 文字打包导出，便于归档与答辩演示
设计取向：检测结果不再是一个孤立的二值掩膜，而是「可视化 + 可量化 + 可解释」的三位一体输出。对一线使用者而言，知道「变了多少」和知道「哪里变了、是什么变了」同样重要。
